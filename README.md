# Simple Calculator

A beginner-friendly command-line calculator developed using Python as part of the **Codveda Technologies Python Development Internship**.

## 📌 Task

### Task 1: Simple Calculator

The objective of this task is to develop a basic calculator that performs four primary arithmetic operations:

- Addition
- Subtraction
- Multiplication
- Division

## 🎯 Objectives

This project fulfills the following requirements:

- Create separate functions for each arithmetic operation.
- Take two inputs from the user.
- Allow the user to select the desired operation.
- Handle division by zero with an appropriate error message.
- Provide a simple and user-friendly command-line interface.

## 🛠️ Technologies Used

- Python 3
- Command Line Interface (CLI)
